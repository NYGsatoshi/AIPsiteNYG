# AIPsiteNYG

AIPsiteNYG is a tenant-aware school and organization portal built as an ASP.NET Core modular monolith. The current codebase is intended for a controlled local demo and internal pilot, not for unrestricted public SaaS operation yet.

The product direction is a school-optimized collaboration platform: announcements, groups, workspaces, project/task tracking, files, direct communication, notifications, auditability, and tenant
