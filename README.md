# AIPsiteNYG

AIPsiteNYG is a tenant-aware school and organization portal built as an ASP.NET Core modular monolith. The current codebase is designed for a controlled internal pilot: one deployable web application, one PostgreSQL database, local file storage by default, and a browser-based UI served by the ASP.NET Core host.

From a product perspective, the system is positioned as a school-optimized collaboration portal
