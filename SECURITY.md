# Security Policy

AIPsiteNYG handles school and organization data. Treat names, accounts, messages, files, audit logs, tenant metadata, and operational logs as sensitive, even in demos.

## Supported scope

Security fixes target the current `main` branch until formal release versioning is introduced.

## Reporting a vulnerability

Report suspected vulnerabilities privately to the repository owner or project maintainer. Do not open public issues containing credentials, raw tokens, tenant data, file contents, signed URLs, exploit details, or personal information.

Include the affected route or feature, reproduction steps, expected and actual behavior, tenant impact if known, and logs with secrets redacted.

## Required security baseline

- Never commit
