Scope terms

Allow
The source kind is eligible under the active scope.
Restrict
Only explicitly named members of a broader source kind would be eligible.
Prioritize
Named members would be preferred while the broader allowed source remains eligible.

Restrict and Prioritize rules are not configured by the current source-scope contract; current configurable source kinds use Allow or Exclude.
