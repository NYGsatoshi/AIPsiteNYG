Preview content is fetched only through backend authorization. The former MVP0 baseline stated: Preview is not available in MVP0. This inspector replaces that limitation. Images, SVG, PDF, video, and text-like files use the short-lived file grant. Archives and unsupported document formats stay closed until an explicit Download. CDN links, public links, and external signed URL sharing are disabled. Preview never uses those links.

This removes the selection from the active workspace inventory. The server rechecks authorization for every file.
